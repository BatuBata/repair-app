## Riwayat dan batas

Pemeriksaan pertama keliru membandingkan isi A5 yang tersela header dan nomor halaman berulang; pemeriksaan diperbaiki dengan mengambil area isi dan kemudian lulus. Margin awal 38mm masih menyebabkan render A5 kedua; diagnostik menunjukkan 39mm dan pengukuran berikutnya memakai 39mm. Pengujian header pertama secara tidak sengaja menimpa PDF sementara `name-a5.pdf` milik fixture coordinator; PNG serta metadata F03 sudah dipertahankan dalam `docs/evidence/T017/A2/boundary-review/`. Seluruh uji selanjutnya memakai salinan fixture privat terpisah. Sebuah permintaan izin pemeriksaan akhir sempat melewati deadline peninjauan otomatis; pengulangan tunggal berhasil.

PHP-FPM privat telah dihentikan, tidak ada MySQL, GUI, WhatsApp, printer, perubahan konfigurasi global, push atau deploy. Printer fisik/Android, beban paralel, FPM/VPS produksi, input batas lain dan QA independen T023 belum diuji; waktu dan memori lokal bukan jaminan produksi. Baris rincian yang sendiri lebih tinggi dari satu halaman tetap harus terpecah sesuai bukti A2.
